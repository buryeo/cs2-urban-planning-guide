# River Delta 交互原型

这是一个独立浏览器样机，用来验证城区规划向导的交互与视觉方向。底图根据 [Paradox 对 River Delta 的文字介绍](https://www.paradoxinteractive.com/games/cities-skylines-ii/features/maps-themes)绘制：弯曲主河道、三角洲分流、缓坡平地与山地边缘。它不是游戏地图的高度图、资源图或精确道路数据，也不会修改《都市：天际线 2》的存档。

## 打开

在本目录运行：

```bash
npm run dev
```

然后打开 <http://127.0.0.1:8765/>。原型不需要安装 npm 依赖；本地需有 Python 3。运行 `npm test` 可检查节点、片区轮廓、水岸、跨河连接和街区密度的基础逻辑。

## 可试的流程

1. 在「读懂场地」改变规划范围和示意主导风向，观察河道、等高线、候选航道与外部道路入口。风向改变时，未锁定的工业区会自动移到 CBD 下风侧。
2. 在「摆放城区节点」拖动圆圈，拖动选中圆圈右下角的控制点调整影响范围；也可增加、删除或锁定节点。初始方案包含四个居住中心、两个独立公园区，以及 CBD、三类交通枢纽、工业、资源、旅游、大学城、科研中心。资源靠近工业并有直接货运走廊；海运枢纽靠近示意航道。点击地图右上角「大画布」可展开画布，编辑面板可单独收起，按 Esc 退出。
3. 在「生成片区」查看节点如何变成陆地上的片区轮廓。点击片区、拖动中心标记或调整影响范围，边界会即时变化；浅虚线表示片区内部的次级规划单元。
4. 在「安排主通道」选择走线并锁定，点击「重新生成走线」，比较候选桥位；返回节点或片区步骤移动中心后，已锁定走线保留中间桥位。
5. 在「预览街区道路」调整密度，比较局部街线与主通道的关系。细密街块纹理只在这一步显示。方案自动保存在浏览器本地，也可导出 JSON。

这版只验证**规划流程和视觉反馈**。精细化的河岸、片区轮廓、等高线、主导风向与候选航道是概念示意，不代表 River Delta 的实测高度、盛行风或游戏航路。资源采集区默认靠近工业，是运输距离建议，不代表真实资源分布；实际资源仍须在游戏资源图层核实。片区轮廓由节点自动划分，不是游戏行政区；最后一步的细线才表示候选街块。工业区的「下风侧」以 CBD 为参照，不能替代对局部风、污染和交通的核实。道路几何没有读取游戏地形、资源和道路接口，也没有交通仿真、真实坡度检查或游戏内铺路能力。下一步若要转成 Mod，需要先验证地图数据读取、覆盖层绘制、道路预览和撤销接口。
