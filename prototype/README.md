# 地形规划交互原型

这是一个独立浏览器样机，用来验证城区规划向导的交互与视觉方向。默认本地样例使用旧金山湾真实高程；另有根据 [Paradox 对 River Delta 的文字介绍](https://www.paradoxinteractive.com/games/cities-skylines-ii/features/maps-themes)绘制的示意底图。它不会修改《都市：天际线 2》的存档。

## 打开

如果本地预览服务尚未运行，在本目录运行：

```bash
npm run dev
```

然后打开 <http://127.0.0.1:8765/>。原型不需要安装 npm 依赖；本地需有 Python 3。运行 `npm test` 可检查节点、片区轮廓、水岸、跨河连接和街区密度的基础逻辑。

## 可试的流程

1. 本地 `local-samples/san-francisco-bay-heightmap.png` 和设色预览同时存在时，页面打开或刷新后会自动进入**旧金山湾地形规划**。步骤 02 直接在地形图上拖放节点。步骤 03 从各节点沿可开发陆地扩展片区，以水域和陡坡为阻隔；离节点太远的山地保留为未规划区，不强迫相邻节点连成一片。圆形风向标可直接拖到地图空白处，位置会在本地保存，拖动不会改变风向。步骤 04～05 展示候选连接与局部街线。「仅看地形」可以暂时隐藏规划图层。规划范围与风向可在步骤 01 调整；风向仍是人为假设，更改后需要检查工业区位置。

   地图上方仍可导入其他 16 位灰度 PNG，按原始长宽比预览。支持《都市：天际线 2》地图编辑器导出的 4096×4096 高程图（[官方格式说明](https://colossalorder.fi/news/development-diary-map-editor/)），也支持宽高均至少 1024 像素的外部玩家样例；后者会明确标记为「仅供预览」。其他高程图没有相应的地形规划预设，不会自动叠加旧金山湾节点。手动导入的文件刷新后需重新选择。Carto 的 GeoTIFF 尚不能直接由此入口打开。

   外部样例试用了 treezen 创作的 [Purerefu](https://steamcommunity.com/sharedfiles/filedetails/?id=3467192129) 高分辨率高程图，原始文件为 2944×1664 的 16 位灰度 PNG。作者在作品页公开提供源文件并允许用于《都市：天际线 2》创作。这是《都市：天际线》玩家地图，并非游戏原版 River Delta，也不是《都市：天际线 2》的原生地图导出。高程图由作者的 Google Drive 提供；本项目不附带该文件。

   旧金山湾样例范围约为西经 122.959°～121.553°、北纬 37.160°～38.273°。运行 `python3 tools/build_real_heightmap.py` 可从 [Mapzen Terrain Tiles（AWS 开放数据）](https://registry.opendata.aws/terrain-tiles/) 下载 16×16 个 256 像素瓦片，拼接成 4096×4096、16 位灰度 PNG，同时生成设色预览和记录经纬度、编码、来源的 JSON。脚本需要 NumPy 和 Pillow；生成文件保存在被 Git 忽略的 `local-samples/`。高程按 `灰度值 = (米数 + 300) × 40` 线性编码，低于 -300 米的海底被截断；极少数低于 -1500 米的源数据异常点由周围有效高程填补。设色图把海拔不高于零米的区域显示为蓝色，规划遮罩据此区分水陆；它不是经过水文核实的海岸与航道。来源涉及 Mapzen，以及美国地质调查局（USGS）的 3DEP/NED、SRTM 和美国国家海洋和大气管理局（NOAA）的 ETOPO1 数据；详细瓦片来源记录在生成的 JSON 中。
2. 在「摆放城区节点」拖动圆圈，拖动选中圆圈右下角的控制点调整影响范围；也可增加、删除或锁定节点。初始方案包含四个居住中心、两个独立公园区，以及 CBD、三类交通枢纽、工业、资源、旅游、大学城、科研中心。资源靠近工业并有直接货运走廊；海运枢纽靠近示意航道。点击地图右上角「大画布」可展开画布，编辑面板可单独收起，按 Esc 退出。
3. 在「生成片区」查看节点如何变成陆地上的片区轮廓。点击片区、拖动中心标记或调整影响范围，边界会即时变化。River Delta 示意模式保留浅虚线次级规划单元；旧金山湾模式以地形栅格生成片区，不再画跨山的几何分割线。
4. 旧金山湾模式的「安排主通道」先生成稀疏的中心连接。选择一条走廊，可在「均衡 / 较短 / 缓坡」间切换，添加蓝色必经点并拖动调整。路线先在连续陆地网格上避开水域与陡坡，再做地形约束下的折线简化与样条式柔化；若必经点无法接通，会保留原候选并提示。橙色圆点标记局部急弯（只作几何提醒），选择和必经点会保存在浏览器本地并随规划 JSON 导出。不能从高程图推断实际桥位、既有道路或航道；River Delta 示意模式仍可比较候选桥位。
5. 在「预览街区道路」调整密度，比较局部街线与主通道的关系。细密街块纹理只在这一步显示。方案自动保存在浏览器本地，也可导出 JSON。

这版只验证**规划流程和视觉反馈**。旧金山湾底图使用真实高程，片区与节点在该图上对齐；水陆分类来自设色预览，坡度是从高程图降采样后的近似值，不是工程测量。图中不含真实航道、既有道路、资源分布或风场。River Delta 模式仍是概念示意。片区由节点自动划分，不是游戏行政区；候选道路还没有按道路等级校核曲率、交通容量、桥梁或水深，也没有游戏内铺路能力。回旋线、端点相切约束、平行道路和景观轴线尚未加入。下一步若要转成 Mod，需要验证游戏地图数据读取、覆盖层绘制、道路预览和撤销接口。
